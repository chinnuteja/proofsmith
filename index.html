Three steps from regression to receipt

1. Qualify and freeze

Require stable original failures in at least 8/10 runs. Bind the check, original source and build recipe before repair.

2. Gate the candidate

Repeat the original and candidate 20 times each. Require matching original failures and zero candidate failures; report weak evidence as inconclusive.

3. Inspect and replay

Keep raw logs, source/check identities and HTML/JSON receipts. Use the CLI, MCP tools or CI exit code.

Reproduce the real results offline

Download and extract the kit. On Linux/WSL with Python 3.12+, clang++, CMake and bubblewrap, use a virtual environment and a fresh output directory:

python -m pip install 'artifacts/proofsmith-0.2.0-py3-none-any.whl[mcp]'
bash scripts/rescore_byteask_comparison.sh --out /tmp/proofsmith-real-recheck

No account or model request is required. Original collector records remain intact; reproduction rebases paths in a temporary input.
